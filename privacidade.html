POLÍTICA DE PRIVACIDADE

Hertz

Última atualização: 08/11/2026

1. DADOS COLETADOS

O Hertz coleta os seguintes dados:

  • ID do usuário (User ID)
  • ID do servidor (Guild ID)
  • Nome de usuário (username)
  • Comandos executados e seus parâmetros

2. FINALIDADE

Os dados são utilizados exclusivamente para:

  • Executar os comandos solicitados pelos usuários
  • Manter o funcionamento do bot nos servidores
  • Melhorar a experiência dos usuários

3. ARMAZENAMENTO

Os dados são armazenados de forma segura.
Os dados são mantidos enquanto o usuário/servidor estiver utilizando o bot.

4. COMPARTILHAMENTO

Os dados NÃO são compartilhados com terceiros.

5. EXCLUSÃO DE DADOS

O usuário pode solicitar a exclusão de seus dados a qualquer momento
utilizando o comando de exclusão no próprio bot ou entrando em contato
pelo canal de suporte.

6. SEGURANÇA

Adotamos medidas razoáveis para proteger os dados contra acesso não autorizado.

7. ALTERAÇÕES

Esta política pode ser atualizada periodicamente.
Alterações significativas serão comunicadas aos usuários.
